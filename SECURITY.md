# Security Policy

## Supported versions

The latest released version on npm receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Instead, report privately via one of:

- GitHub's [private vulnerability reporting](https://github.com/clappingmonkey/opencode-circadian/security/advisories/new)
- Email: clappingmonkey33@gmail.com

Please include a description, reproduction steps, and impact if known. You'll get
an acknowledgement as soon as possible, and a fix and disclosure will be
coordinated with you.
